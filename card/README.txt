GitHub 업로드 방법
1. 압축을 풉니다.
2. GitHub 저장소의 card 폴더를 엽니다.
3. card 폴더 안 기존 파일을 모두 삭제합니다.
4. 이 최종본의 card 폴더 안 파일 7개를 그대로 업로드합니다.
5. Commit changes를 누릅니다.
6. 1~3분 뒤 위 링크를 새로고침합니다.

이번 최종본 반영 사항
- 인스타그램 링크와 아이콘 완전 제거
