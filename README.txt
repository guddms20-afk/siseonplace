시선플레이스 모바일 명함 최종본

업로드 방법
1. GitHub 저장소의 card 폴더 안 기존 파일을 삭제합니다.
2. 이 압축파일을 풀고 안의 파일 7개를 card 폴더에 업로드합니다.
3. Commit changes를 누릅니다.
4. 약 1~3분 뒤 기존 링크에서 확인합니다.

링크
https://guddms20-afk.github.io/siseonplace/card/

포함 기능
- 시선플레이스 대표 박형은 연락처 저장
- 연락처 프로필 사진 포함
- 카카오 상담, 전화, SNS, 이메일, 홈페이지 연결
- 아이폰 Safe Area 및 모바일 반응형
- 버튼 터치/등장 애니메이션
- 카카오톡 링크 미리보기 이미지
