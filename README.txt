GitHub 업로드 방법
1. 기존 siseonplace 저장소로 이동
2. Add file > Upload files
3. 압축을 푼 뒤 위 파일 6개를 모두 업로드
4. 같은 이름의 기존 파일이 있다면 덮어쓰기
5. Commit changes 클릭
6. 1~3분 뒤 https://siseon00p.github.io/siseonplace/ 접속

- index.html, style.css, script.js는 반드시 저장소 최상단에 있어야 합니다.
